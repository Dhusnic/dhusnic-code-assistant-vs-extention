Infraon Code Assistant 0.25.0 is out for Mac. Long tasks now run to the end, and the task list keeps up 🚀

🆕 What's new
• Long tasks run to the end: an agent can now take up to 1200 steps per request (was 50–120), so building a whole feature or project no longer stops halfway with "Send continue"
• The Tasks card keeps up: the agent marks each step done as it works, instead of piling everything under step 1
• A step left open when the agent stops now shows as paused, not as an endless spinner
• Projects the agent creates from scratch get their tests run automatically before it finishes

🔄 Already installed? Update in 1 minute
1. Download and extract the attached zip: InfraonCodeAssistant-Mac-Installer.zip
2. Right-click Install-InfraonAssistant.command → Open → Open
3. That's it. It detects your installed version and updates it. Your API key and settings are kept, so nothing is asked.
4. If VS Code was open: Cmd+Shift+P → "Developer: Reload Window"

🍎 New user? Install in 2 minutes
1. Extract the zip, right-click Install-InfraonAssistant.command → Open → Open (first time only, macOS asks for confirmation)
2. Paste your API key when it asks (the only question)
3. VS Code opens. Click the "Infraon Assistant" icon on the left bar

If the .command doesn't open: open Terminal, type "bash " (with a space), drag install.sh into the window, press Return.

⚠️ Notes
• Connect to the office network / VPN first.
• Don't double-click the .vsix file, only run the .command / install.sh.
• Need to change your key? Cmd+Shift+P → "Infraon Assistant: Set API Key"
• Don't share your API key in chat. Ask me for yours if you don't have one.

Windows users: use the separate Windows installer zip.

Try it: switch to Plan mode and ask "Build a small REST API with tests for a todo list"
