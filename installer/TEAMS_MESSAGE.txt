Infraon Code Assistant 0.34.0 is out: updates in the sidebar, and bug fixes that start with the real cause 🔄🐞

🆕 What's new
• Updates in the sidebar: see your version and update status, and Check now / Install / Reload with one click. Update errors now explain the cause in plain words, with a button to fix it (e.g. open the missing setting)
• Bug fixes start with the real cause: when you ask for a fix, the agent must first prove the root cause (code it read + a reproduction it ran) before it may change your code, and the reproduction must pass afterwards. No more patching the symptom. Turn off with infraonAssistant.diagnoseFirst = off
• File and folder tools: the agent can create folders, move/rename, copy and delete files and folders (with approval, and undoable with rewind), and show a folder tree
• Screenshots: the agent can capture your screen, the VS Code window, another app's window or part of the screen, and tell you what it sees
• Long chats stay on track: compaction starts in time, long multi-step requests are compacted too, and rules you gave early on are no longer lost after several compactions
• Skills work by themselves: ask for e.g. "the release notes as a Word document" and the agent picks the right skill (only when it clearly fits)
• Type / anywhere in your message to pick a skill. A skill in the middle of a sentence runs too: "please /code-review the login changes"
• Press ↑ in the message box to bring back a message you sent before (↓ goes forward). Edit it, then press Enter
• New 🕒 clock button at the top of a session: lists every message you sent with its time. Click one and the chat jumps to it
• File edits now show a ✎ pen instead of a ✓, so changes stand out from reads
• No more endless loops: if the model keeps repeating the same command after two reminders, it is stopped and tells you
• Your message stays pinned at the top of the chat while you scroll through the agent's work
• Replies, tool calls and approvals now sit on a timeline, with a status dot for each step (running, done, failed, waiting for you)
• Compact (click the context ring, or /compact) now works while the agent is busy: it runs before the next step instead of showing an error
• Already on 0.26.0 or later? You don't need the installer: the update installs by itself, just click "Reload Now" when asked (or Ctrl+Shift+P → "Infraon Assistant: Check for Updates")
