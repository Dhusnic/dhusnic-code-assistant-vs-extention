Infraon Code Assistant 0.26.0 is out, and from now on it updates itself 🚀

🆕 What's new
• Automatic updates: this is the last time you install an update by hand. New versions now install by themselves from our gateway server, and you just click "Reload Now" when asked
• The reload prompt waits until your agents finish, so nothing gets interrupted
• Want to check now? Ctrl+Shift+P (Mac: Cmd+Shift+P) → "Infraon Assistant: Check for Updates"
• Every update is signed and verified before it's installed

⬇️ Download (office network / VPN only)
• Windows: https://172.16.48.75:30400/infraon-assistant/downloads/InfraonCodeAssistant-Installer.zip
• Mac: https://172.16.48.75:30400/infraon-assistant/downloads/InfraonCodeAssistant-Mac-Installer.zip
If your browser says "Your connection is not private", that's expected: our server uses an internal certificate. Click Advanced → Proceed to 172.16.48.75.

🪟 Windows: install or update (1 minute)
1. Right-click the downloaded zip → Extract All
2. Double-click Install-InfraonAssistant.bat (SmartScreen warning: More info → Run anyway)
3. Already installed: nothing is asked, and your API key and settings are kept. New user: paste your API key when asked
4. If VS Code was open: Ctrl+Shift+P → "Developer: Reload Window"

🍎 Mac: install or update (1 minute)
1. Double-click the downloaded zip to extract it
2. Right-click Install-InfraonAssistant.command → Open → Open
3. Already installed: nothing is asked. New user: paste your API key when asked
4. If VS Code was open: Cmd+Shift+P → "Developer: Reload Window"
If the .command doesn't open: open Terminal, type "bash " (with a space), drag install.sh into the window, press Return.

⚠️ Notes
• Run only the installer (.bat / .command). Don't double-click the .vsix file.
• Need to change your key? Ctrl/Cmd+Shift+P → "Infraon Assistant: Set API Key"
• Don't share your API key in chat. Ask me for yours if you don't have one.
