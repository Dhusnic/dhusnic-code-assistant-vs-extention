Infraon Code Assistant (our AI coding assistant in VS Code, running on the company LLM) is ready to install. One script sets everything up.

📦 Install (2 minutes)
1. Download and extract the attached zip: InfraonCodeAssistant-Installer.zip
2. Double-click Install-InfraonAssistant.bat
3. Paste your API key when it asks (that is the only question)
4. VS Code opens, then click the "Infraon Assistant" icon on the left bar

✅ It installs VS Code if you don't have it, installs the extension and configures it for you.

⚠️ Notes
• Run only Install-InfraonAssistant.bat. Don't double-click the .vsix file (it opens the Visual Studio installer and fails).
• Connect to the office network / VPN first.
• If VS Code is already open, run Ctrl+Shift+P → "Developer: Reload Window" once.
• Windows may show a SmartScreen warning for the .bat: click More info → Run anyway.
• Don't share your API key in chat. Ask me for yours if you don't have one.
